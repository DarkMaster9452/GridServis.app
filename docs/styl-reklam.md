reklamy. Ak je niečo nejasné (formát, cieľ, ponuka), opýtaj sa. Nič si
nevymýšľaj.

### Mriežka (poznávacie znamenie)

Mriežka je na **každom** materiáli, rovnako ako na webe.
- **Na bielom:** 1 px čiary `#e4e8ef`. Krok na webe aj v e-mailoch je 34 px,
  v reklame 1080 px širokej asi 48 px. Je jemná, nesmie prebíjať text.
- **Na modrom:** biele čiary 2 px s priehľadnosťou 12–30 %, krok ≈ šírka / 16
  (68 px pri 1080). Najvýraznejšia je v strede a ku krajom slabne.
- Dlaždice pre e-maily: `https://www.gridservis.app/assets/img/email-mriezka.png`
  (biela) a `…/email-mriezka-modra.png` (modrá), 34×34 px.

### Písmo

- Nadpisy: **hrubé bezpätkové písmo (800)** s tesným prestrkaním (letter-spacing −0,02 až −0,03 em).
  V Canve použi písmo z pôvodných reklám (geometrický grotesk, vzhľadom ako
  Poppins; presný názov over v Canve). V HTML: `Poppins, Inter, 'Segoe UI', Roboto, Arial, sans-serif`.
- Text: to isté písmo v bežnej hrúbke, sivé popisy menšie.
- Rukopis (len poznámka so šípkou): modré rukou písané písmo (napr. Caveat),
  mierne natočené. Najviac jedno na materiál.
- Kódy a čísla licencií: neproporcionálne písmo (`ui-monospace, Menlo, Consolas`).

**Dvojfarebný nadpis** je hlavný prvok: prvá časť čierna (na modrom
pozadí biela), **posledné 1–3 slová modré**. Príklady: „Čo je **GridServis?**“,
„Prebehlo všetko **v poriadku?**“, „Licencia je **aktívna**“.

## 5. Tón a text

- **Slovenčina, vykanie** („vám“, „váš servis“, „Stiahnite si“). Malým písmenom
  ako v reklamách, nie „Vám“.
- **Krátko a konkrétne**, z pohľadu dielne: čo sa zlepší v jej bežnom dni.
  Žiadny marketingový balast, žiadne „revolučný“, „najlepší na trhu“, „AI“.
- **Úprimne:** GridServis je nový. V e-mailoch píšeme „len začíname“
  a prosíme o názor, aj kritický. Neprikrášľuj.
- Podpis: **„Tím GridServis“**.
- Emoji nepoužívame. Šípka „→“, fajka „✓“ a „↗“ áno.
- Slovenská typografia: „úvodzovky“, pomlčka „—“, desatinná čiarka a medzera
  pred € („19,99 €“), dátum „11. 10. 2026“, nezlomiteľná medzera po
  jednopísmenových predložkách (v, k, s, z, o, a, i, u), napr. `v&nbsp;poriadku`.

## 7. Postup výroby (takto vznikli aj e-maily)

1. **Zadanie.** Zisti kanál a formát, cieľ (demo, predplatné, spätná väzba,
   nová verzia), komu je to určené a či platí nejaká ponuka. Ak niečo chýba,
   opýtaj sa.
2. **Predlohy.** Pozri si obe reklamy (oddiel 2), ešte kým začneš kresliť.
3. **Kostra.** Vyber formát (oddiel 6) a 3–6 blokov (oddiel 4) v typickom poradí.
4. **Text.** Napíš ho podľa oddielu 5: dvojfarebný nadpis, 1–2 vety, CTA.
   Over ceny a kontakty podľa oddielu 1.
5. **Výroba.** Vyber si jednu cestu:
   - **A) Canva:** skopíruj pôvodnú reklamu (`copy-design`), zmeň texty
     a obrázky, prípadne rozmer (`resize-design`) a exportuj PNG
     (`export-design`). Najvernejšia cesta.
   - **B) HTML → PNG:** vezmi šablónu z oddielu 9, vyplň ju a vyrenderuj
     cez Playwright (`render.js`) presne v cieľovom rozmere.
   - **C) Python / PIL:** na pozadia a hlavičky (oddiel 9, `pozadie.py`).
6. **Kontrola.** Výsledok si vždy pozri ako obrázok. Porovnaj ho
   s predlohou a prejdi kontrolný zoznam (oddiel 8). Prekrývanie, odrezaný
   text alebo slabý kontrast oprav a vyrenderuj znova.
7. **Odovzdanie.** Odovzdaj:
   - PNG v presnom rozmere (pre web aj JPG do 500 kB),
   - text príspevku (caption) a nadpis pre reklamný systém,
   - alt text obrázka (1 veta, čo je na obrázku),
   - pri reklame 2–3 varianty nadpisu na A/B test.
8. **E-mail navyše:** HTML aj textová verzia. Najprv pošli test na vlastnú
   adresu majiteľa (cez Resend) a **zákazníkom nič neposielaj bez jeho súhlasu**.

// npm i playwright  (alebo NODE_PATH=$(npm root -g) ak je nainštalovaný globálne)
// node render.js prispevok.html prispevok.png 1080 1350
// node render.js story.html story.png 1080 1920
const { chromium } = require('playwright');
(async () => {
  const [, , vstup, vystup, w, h] = process.argv;
  const b = await chromium.launch();
  const p = await b.newPage({ viewport: { width: +w, height: +h }, deviceScaleFactor: 1 });
  await p.goto('file://' + require('path').resolve(vstup));
  await p.waitForLoadState('networkidle');
  await p.screenshot({ path: vystup });
  await b.close();
})();

### 9.4 Modré pozadie s mriežkou a logom: `pozadie.py`

Takto vznikli hlavičky e-mailov. Funguje pre ľubovoľný rozmer.

```python
# pip install pillow
# python3 pozadie.py 1080 1920 pozadie.png [gridservis-logo-biele.png]
import sys
from PIL import Image, ImageDraw, ImageChops
W, H, OUT = int(sys.argv[1]), int(sys.argv[2]), sys.argv[3]
KROK = round(W / 16)                        # 68 px pri šírke 1080–1120
A, B = (37, 99, 235), (29, 78, 216)         # #2563eb → #1d4ed8
# diagonálny prechod modrej
v = Image.linear_gradient('L')                        # zhora nadol
t = Image.blend(v.rotate(90), v, 0.6).resize((W, H))  # 40 % zľava, 60 % zhora
img = Image.composite(Image.new('RGB', (W, H), B), Image.new('RGB', (W, H), A), t)
# biela mriežka, ku krajom slabne
mriez = Image.new('L', (W, H), 0)
d = ImageDraw.Draw(mriez)
for x in range((W // 2) % KROK, W, KROK): d.line([(x, 0), (x, H)], fill=255, width=2)
for y in range(0, H, KROK): d.line([(0, y), (W, y)], fill=255, width=2)
maska = ImageChops.invert(Image.radial_gradient('L')).resize((W, H))
mriez = ImageChops.multiply(mriez, maska).point(lambda v: int(v * 0.30))
img.paste((255, 255, 255), (0, 0), mriez)
# voliteľne biele logo + tenká linka doprava (ako „Download our App“)
if len(sys.argv) > 4:
    logo = Image.open(sys.argv[4]).convert('RGBA')
    lh = round(W * 0.045); lw = round(logo.width * lh / logo.height)
    logo = logo.resize((lw, lh), Image.LANCZOS)
    x0, y0 = round(W * 0.06), round(min(W, H) * 0.12)
    img = img.convert('RGBA'); img.alpha_composite(logo, (x0, y0))
    ImageDraw.Draw(img).line([(x0 + lw + 28, y0 + lh // 2), (W - x0, y0 + lh // 2)], fill=(255, 255, 255, 200), width=3)
img.convert('RGB').save(OUT, optimize=True)
```

Hlavička so screenshotom (`email-spatna-vazba.png`, 1120×560) je to isté
pozadie. Logo je vľavo hore a od výšky 150 px je vložený `prehlad.png`
v okne s lištou a tromi bodkami, so zaoblením 22 px a rozmazaným tieňom
(GaussianBlur 26, farba `rgba(8,20,60,.43)`). Spodok okna je odrezaný okrajom
obrázka.

## 11. Ak robíš e-mail

Hotová implementácia je v repozitári. Nové e-maily skladaj z nej:

- `api/_email-vzhlad.js` obsahuje obal a bloky z oddielu 4. Farby, písmo,
  hlavičky (inline obrázky cez `cid:` so záložným odkazom na web), preheader,
  pätička s hodnotami a odoslanie cez Resend.
- `api/_email.js` obsahuje všetky e-maily: licencia, presun, demo, spätná väzba
  s ponukou 3 mesiacov, neúspešná platba, koniec predplatného, obnova,
  skúšobná licencia, koniec skúšobnej, týždeň po deme, hodnotenie 1–10,
  nová verzia. Pri novom e-maile skopíruj najbližší z nich.
- Náhľad hotového e-mailu: [`docs/reklamy/email-spatna-vazba.jpg`](reklamy/email-spatna-vazba.jpg).

Pravidlá e-mailov: rozloženie z tabuliek a len inline štýly. Každé pozadie
má aj `bgcolor`, lebo niektoré klienty CSS pozadie zahodia. Šírka je najviac
560 px. Modré tlačidlo má modrú trikrát (td `bgcolor`, td štýl aj odkaz)
a pod ním je obyčajný odkaz. Hlavička má pevnú výšku a viditeľný alt text,
aby sa pri zablokovaných obrázkoch nezbalila. K HTML patrí vždy textová
verzia. Vysokú prioritu (`X-Priority: 1`) majú len e-maily s kódom alebo
platbou. Proti dvojitému odoslaniu slúži Idempotency-Key. Pred ostrým
odoslaním e-mail vyrenderuj (Playwright, šírka 700 px), pozri si ho a pošli
test na adresu majiteľa.
